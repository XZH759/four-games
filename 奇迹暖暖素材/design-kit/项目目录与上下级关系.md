# 项目目录与上下级关系

`design-kit/` 是交给 Cursor 的实施说明和参考资源，不是新的应用项目。它应作为现有游戏项目根目录的一级子目录存在。

## 放入现有项目后的结构

```text
your-game-project/
├─ package.json
├─ src/                              # 现有应用源码；由 Cursor 按项目技术栈修改
│  ├─ avatar/
│  │  ├─ avatar-types.ts
│  │  ├─ avatar-manifest.ts
│  │  └─ AvatarRenderer.tsx
│  └─ components/
│     └─ AvatarOptionCard.tsx
├─ public/
│  └─ assets/
│     ├─ ui/                         # 从 design-kit/assets/ui/ 复制
│     │  ├─ starlight-arch.svg
│     │  ├─ panel-frame.svg
│     │  ├─ compass-star.svg
│     │  ├─ selected-check.svg
│     │  └─ sparkle.svg
│     └─ avatar/                     # 正式 1600×2400 透明人物图层
│        ├─ base/
│        │  ├─ slender/
│        │  ├─ balanced/
│        │  └─ lively/
│        ├─ faces/
│        │  ├─ eyes/
│        │  ├─ eyebrows/
│        │  └─ mouths/
│        ├─ hair/
│        │  └─ cloud-curl/
│        ├─ outfits/
│        │  ├─ star-scholar/
│        │  ├─ morning-traveler/
│        │  └─ night-gown/
│        ├─ accessories/
│        │  └─ star-book/
│        └─ effects/
└─ design-kit/                       # 本交付文件夹，保持完整
   ├─ 00_交给Cursor_执行顺序.md
   ├─ README_先看这里.md
   ├─ 项目目录与上下级关系.md
   ├─ prompts/                       # 01–06 阶段指令、出图提示词、导出规范
   ├─ interfaces/                    # 每次只交给 Cursor 一个子目录
   │  ├─ COMMON_REQUIREMENTS.md      # 所有界面的公共质量基线
   │  ├─ 01_initial-avatar/
   │  │  ├─ reference.png
   │  │  ├─ CURSOR_TASK.md
   │  │  └─ QA_CHECKLIST.md
   │  ├─ 02_companion-selection/
   │  ├─ 03_task-list/
   │  ├─ 04_level-map/
   │  ├─ 05_knowledge-gallery/
   │  ├─ 06_shop-collection/
   │  ├─ 07_featured-outfits/
   │  ├─ 08_blind-box/
   │  ├─ 09_achievements/
   │  └─ 10_chapter-complete/
   ├─ references/                    # 跨页面共用视觉规则，不再集中存图
   ├─ styles/                        # 主题变量与动画参考
   ├─ assets/
   │  ├─ ui/                         # 可直接复制的 SVG
   │  └─ avatar/                     # 人物资源目录说明，不放最终占位图
   ├─ src/                           # React 分层渲染示例，不应脱离项目盲目覆盖
   ├─ scripts/                       # 人物图片尺寸与透明通道检查
   └─ checklists/                    # 最终视觉与交互验收清单
```

## 正式人物素材命名示例

```text
public/assets/avatar/
├─ base/balanced/
│  ├─ body-skin-03.webp
│  └─ face-soft-oval-skin-03.webp
├─ faces/
│  ├─ eyes/soft-oval-violet.webp
│  ├─ eyebrows/gentle-01.webp
│  └─ mouths/soft-smile-01.webp
├─ hair/cloud-curl/
│  ├─ silver-lilac-back.webp
│  ├─ silver-lilac-side.webp
│  └─ silver-lilac-front.webp
├─ outfits/star-scholar/
│  ├─ balanced-back.webp
│  ├─ balanced-main.webp
│  ├─ balanced-front.webp
│  └─ balanced-shoes.webp
└─ accessories/star-book/
   ├─ head.webp
   └─ hand.webp
```

所有人物图层均须使用相同的 `1600×2400` 透明画布、人物中心点和脚底基线；即使图层内容很小，也不得自动紧裁切。

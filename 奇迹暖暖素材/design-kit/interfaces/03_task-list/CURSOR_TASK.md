# 界面 03：学习任务清单

先读取：

```text
design-kit/interfaces/COMMON_REQUIREMENTS.md
design-kit/interfaces/03_task-list/reference.png
```

只制作“学习任务清单”界面。

## 页面目标

让用户一眼理解本次任务总进度、任务分组、每项要求、奖励以及下一步。参考图中的大标题、总进度面板、标签页、任务行和底部双操作只作为信息层级参考。

## 必须实现

1. 顶部展示真实任务完成数与总数，进度节点由数据计算。
2. 每日任务、章节目标、终极目标等分组复用统一标签组件。
3. 任务行包含序号/图标、标题、说明、奖励预览、状态和进度。
4. 完成、可前往、锁定、可领取、已领取必须有不同状态与可访问标签。
5. “前往”跳转到真实目标；领取操作具备加载、防重复和成功反馈。
6. 奖励数量与物品来自真实数据，不硬编码参考图内容。
7. 手机端任务行重排为上下结构，奖励和主操作仍可清楚点击。

## 禁止

- 用纯展示进度替代真实任务状态；
- 已完成任务仍显示可重复领取；
- 为塞入一屏而把正文缩得过小或隐藏必要说明。

完成后执行同目录的 `QA_CHECKLIST.md`。

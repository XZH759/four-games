# 界面 01：初始形象创建

先读取：

```text
design-kit/interfaces/COMMON_REQUIREMENTS.md
design-kit/interfaces/01_initial-avatar/reference.png
design-kit/src/avatar/
design-kit/styles/
```

只制作“初始形象创建”界面，不要同时修改伙伴、任务、地图或商城页面。

## 页面目标

把当前页面制作成清晰的角色创建舞台：顶部是标题与简短说明，左侧是外观定制，中央是完整人物预览，右侧是体型和初始套装，底部是角色名称、随机生成与确认进入。

## 必须实现

1. 中央人物、体型卡和套装卡复用同一个角色配置与 `AvatarRenderer`。
2. 发型、发色、肤色、眼睛、脸型、配饰、体型和套装切换后，所有预览保持同一人物。
3. 选择卡有即时按下、金色选中边框和勾选章反馈。
4. 新图层加载完成前保留旧人物，再进行约 220ms 的交叉淡化，不得闪白。
5. 随机生成按姓名、外观、套装分段更新，总时长不超过 650ms。
6. 名称为空时在输入框附近提示；确认时防止重复提交，保存成功后才跳转。
7. 桌面保持三栏舞台；平板压缩两侧面板；手机改为人物舞台优先、选项分组折叠或横向滚动。

## 禁止

- 用简单 CSS/SVG 几何人物冒充最终角色；
- 分别硬编码中央人物、体型卡和套装卡图片；
- 为接近参考图而牺牲现有字段、保存逻辑或后续路由；
- 使用大幅旋转、翻牌或全屏闪光切换人物。

完成后执行同目录的 `QA_CHECKLIST.md`。

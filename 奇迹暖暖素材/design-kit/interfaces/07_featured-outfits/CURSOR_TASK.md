# 界面 07：限时服饰与横版商品陈列

先读取：

```text
design-kit/interfaces/COMMON_REQUIREMENTS.md
design-kit/interfaces/07_featured-outfits/reference.png
```

只制作“限时服饰上架/精选商品陈列”界面。如果项目没有独立对应页面，先报告缺口，不要创建脱离真实商品系统的静态页面。

## 页面目标

在宽屏上以高密度但整齐的商品卡展示精选套装，在窄屏上改为两列或单列商品列表。参考图的十张人物卡仅用于说明卡片比例、统一底线、标签和购买层级。

## 必须实现

1. 标题、活动说明、时间、商品列表、标签、价格与货币类型来自真实数据。
2. 商品卡保持统一人物展示区、名称区、价格区和主操作区，人物脚底或商品底线对齐。
3. 支持已拥有、可购买、余额不足、限时结束和不可用状态。
4. 购买前后状态同步到商城、衣柜和套装收集数据。
5. 桌面按可用宽度自适应列数；手机不能把十张卡压缩在同一行。
6. 若商品图是分层人物，复用角色渲染器或统一缩略图生成方式。

## 禁止

- 复制参考图的具体人物、套装名称、标签或价格；
- 为保持海报感而把整个商品区固定为单一宽高；
- 与主商城建立第二套独立且不同步的购买状态。

完成后执行同目录的 `QA_CHECKLIST.md`。

# 视觉与交互验收清单

## 人物
- [ ] 中央角色、体型卡、套装卡是同一角色配置。
- [ ] 角色头顶、发饰、鞋子完整。
- [ ] 人物没有被横向或纵向拉伸。
- [ ] 所有图层脚底基线一致。
- [ ] 前发、后发、服装前后层级正确。
- [ ] 快速切换时不闪白。
- [ ] 未加载完成时继续显示旧角色。

## 卡片
- [ ] 所有卡片尺寸一致。
- [ ] 选中状态有边框和勾选，不只依靠颜色。
- [ ] hover 上移不超过 2–4px。
- [ ] 卡片中文字不遮挡角色。
- [ ] 未选中角色仍清晰。

## 操作
- [ ] 点击后 220ms 内出现反馈。
- [ ] 随机生成不超过 650ms。
- [ ] 确认按钮防重复点击。
- [ ] 名称错误就地提示。
- [ ] 键盘可完成全部操作。
- [ ] reduced-motion 生效。

## 响应式
- [ ] 1440×900 正常。
- [ ] 1024×768 正常。
- [ ] 390×844 正常。
- [ ] 没有横向滚动。
- [ ] 移动端角色优先显示。
- [ ] 选项卡可横向滑动但不截断文字。

## 教育测试约束
- [ ] 没有战力、稀有度和属性值。
- [ ] 外观不影响题目或能力。
- [ ] 没有正确率或答案提示。
- [ ] 动画不会持续干扰阅读。

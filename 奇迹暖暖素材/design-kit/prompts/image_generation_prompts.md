# 人物与服装素材生成提示词

## 使用方法

先生成“母版角色”，确认脸、比例、站姿和光线。后续所有体型、发型和服装都使用图像编辑模式，只改变指定部位，避免每张图变成不同人物。

统一要求：
- 正面全身；
- 双脚完整可见；
- 身体居中；
- 透明背景；
- 1600×2400；
- 同一镜头、同一人物、同一脚底位置；
- 柔和二次元游戏立绘；
- 不使用任何现有游戏角色或品牌标志。

## 发型变体

保持脸、身体、服装、姿势完全不变，仅替换头发。输出时分别生成：
1. 云雾长卷发；
2. 星环编发；
3. 晨光短发；
4. 柔波中长发；
5. 半扎蝴蝶结；
6. 低双辫。

每个发型都需要前发、后发、侧发遮挡关系清晰，发丝层次和高光统一，不改变脸型。

## 三种体型

以同一角色为基础，脸、发型、服装、镜头和脚底位置不变。

纤细型：肩略窄、四肢稍长、腰线稍高、轻盈站姿。
标准型：比例均衡、自然站姿。
活泼型：重心略低、四肢略短、轮廓略圆、站姿更有动势，但不能表现为胖。

# 界面 09：徽章与成就

先读取：

```text
design-kit/interfaces/COMMON_REQUIREMENTS.md
design-kit/interfaces/09_achievements/reference.png
```

只制作“成就与徽章”界面。

## 页面目标

使用分类导航、核心里程碑、近期达成、统计信息和阶段奖励轨道，清楚展示长期学习成果。徽章应是数据驱动的可复用组件，不是固定拼贴图。

## 必须实现

1. 成就分类、完成条件、进度、获得时间、点数和奖励来自真实数据。
2. 核心里程碑卡显示获得/进行中/锁定状态，完成条件与日期可读。
3. 近期达成区域按真实时间排序，并处理数量不足或为空。
4. 左侧或顶部统计展示已获得徽章、完成成就、成就点数和连续天数。
5. 阶段奖励轨道显示阈值、已领取、可领取、进行中和未解锁状态。
6. 奖励领取具备防重复、加载、成功和失败回滚。
7. 手机端把侧栏改为摘要和分类控件，徽章卡可横向滚动或单列展示。

## 禁止

- 复制参考图徽章图案、英文成就名或角色头像；
- 仅依赖金银颜色表示获得状态；
- 把“已领取”状态保存在与真实奖励数据不同步的临时变量中。

完成后执行同目录的 `QA_CHECKLIST.md`。

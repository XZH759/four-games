# 初始形象创建验收

- [ ] Cursor 定位的是现有初始形象页面，没有创建独立项目。
- [ ] 中央人物、体型卡、套装卡使用同一 `AvatarConfig`。
- [ ] 更换套装不会重置发型、脸型、眼睛或肤色。
- [ ] 更换体型不会变成另一张脸，人物也没有拉伸。
- [ ] 所有人物图层中心点和脚底基线一致。
- [ ] 快速连续选择时不闪白、不显示混合错误图层。
- [ ] 名称校验、随机生成、保存和确认跳转仍正常。
- [ ] 选中、悬停、按下、键盘焦点和禁用状态清楚。
- [ ] 手机端可以完成全部设置，主按钮不遮挡内容。
- [ ] 已测试刷新后配置恢复以及资源加载失败状态。
- [ ] 已输出三种视口截图和修改文件列表。
- [ ] 正式人物素材未就位时明确标记占位，不声称最终立绘完成。

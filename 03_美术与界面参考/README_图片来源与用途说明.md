# 图片来源与用途说明

## 来源判断

- 文件名带 `OpenAI生成`：图片二进制中检出 C2PA 信息，包括 `OpenAI Media Service API` 和 `trainedAlgorithmicMedia`。
- 文件名带 `外部参考`：作为构图、导览或信息层级参考使用，不是项目原创美术资产。
- 文件名带 `来源未标注`：本地文件未检出可验证的来源信息，因此只描述内容，不推断作者或平台。

## 目录用途

- `01_角色创建`
  - 完整界面效果图
  - 空白场景背景
  - 六种职业角色全身图
- `02_学习伙伴`
  - Q 版学习伙伴选择界面参考
- `03_世界地图与关卡`
  - 地图优先方案、组件状态表、移动端地图成品
- `04_跑酷模块`
  - 四种区域赛道、操作引导、奖励与失败反馈、路线选择
- `05_AI素养挑战赛`
  - 加入房间、候场、答题和结果反馈
- `06_外部来源参考`
  - 外部地图和导览图，仅作视觉研究参考

## 使用边界

OpenAI 生成图片可用于项目原型和视觉探索，但最终上线前仍应检查文字错误、构图一致性、人物手部、透明通道和响应式裁切。外部参考图片不应直接作为商业项目成品使用。

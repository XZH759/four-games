# 商城与套装收集验收

- [ ] 人物预览、商品缩略图和套装进度使用一致的资源清单。
- [ ] 分类、搜索或筛选后商品数量与真实数据一致。
- [ ] 已拥有、可购买、余额不足、加载中和售罄状态清楚。
- [ ] 快速点击购买不会重复扣费或重复发放物品。
- [ ] 购买失败会回滚界面状态并显示可理解提示。
- [ ] 试穿不会永久覆盖已保存装扮，重置后恢复正确。
- [ ] 收集进度、缺失件、奖励解锁和领取状态正确。
- [ ] 手机端商品卡、价格和按钮不拥挤，人物预览可收起或缩短。
- [ ] 长商品名、空分类和图片失败不会破坏网格。
- [ ] 已输出三种视口截图以及购买/试穿状态测试结果。

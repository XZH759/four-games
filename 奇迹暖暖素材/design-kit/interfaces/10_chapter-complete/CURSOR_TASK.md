# 界面 10：章节结算

先读取：

```text
design-kit/interfaces/COMMON_REQUIREMENTS.md
design-kit/interfaces/10_chapter-complete/reference.png
```

只制作“章节结算/完成奖励”界面。

## 页面目标

让用户按“完成结果 → 章节完成 → 奖励 → 下一步”阅读。可以有庆祝氛围，但必须保证奖励来源、领取状态和后续操作真实可靠。

## 必须实现

1. 展示真实章节名称、提交数量、完成条件、获得货币与新物品。
2. 奖励卡使用统一组件，区分货币、新物品、稀有奖励和已加入收藏状态。
3. 结算数据只处理一次；刷新、返回或重复进入不能重复发奖。
4. “暂时休息”“进入商城”“继续下一章节”等操作遵循真实解锁和路由规则。
5. 下一章节未解锁时显示原因，不得提供无效主按钮。
6. 庆祝粒子、丝带、光晕和数字动画短而克制，并支持减少动态模式。
7. 手机端先显示完成结论和奖励，再显示说明与操作；按钮可换行但层级不变。

## 禁止

- 用前端固定数字冒充结算结果；
- 重复进入页面时再次发放奖励；
- 让庆祝动画遮挡奖励文字或阻止用户继续操作；
- 使用参考图人物、奖励物和章节文案作为正式内容。

完成后执行同目录的 `QA_CHECKLIST.md`。

# 奇迹暖暖素材导航

本目录按界面制作流程划分为 10 个环节：

1. `01_初始形象创建`
2. `02_学习伙伴选择`
3. `03_学习任务清单`
4. `04_关卡地图`
5. `05_AI知识图鉴`
6. `06_商城与套装收集`
7. `07_限时服饰上架`
8. `08_抽卡盲盒`
9. `09_徽章成就系统`
10. `10_章节结算`

其他目录：

- `00_Cursor交付包`：可直接交给 Cursor 的 ZIP 包。
- `00_需求与来源`：原始需求文字与后续来源说明。
- `design-kit`：按界面拆分的 Cursor 任务、参考图、QA 清单和公共要求。
- `人物立绘素材`：嘉然、贝拉、向晚、乃琳、心宜、思诺的原版与 Q 版素材；OpenAI 生成衍生图单独放在 `Q版/OpenAI生成`。
- `99_重复与待确认`：哈希相同的重复图片或暂未归入正式交付的内容。

图片文件名已标注来源和作用，例如：

- `OpenAI生成_奇迹暖暖风_初始形象创建界面.png`
- `OpenAI生成_Q版伙伴卡片框.png`
- `OpenAI生成_思诺_Q版角色立绘.png`

`design-kit` 内部参考图为独立副本，因此整理根目录原图不会影响 Cursor 指令中的相对路径。

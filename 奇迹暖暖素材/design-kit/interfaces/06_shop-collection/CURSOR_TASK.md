# 界面 06：商城与套装收集

先读取：

```text
design-kit/interfaces/COMMON_REQUIREMENTS.md
design-kit/interfaces/06_shop-collection/reference.png
design-kit/src/avatar/
```

只制作“商城/衣柜/套装收集”界面。

## 页面目标

形成“当前装扮预览 → 分类筛选 → 商品浏览 → 试穿/购买 → 套装收集进度”的完整流程。桌面可左侧人物、右侧商品网格、底部套装进度；手机按人物预览、分类、商品和收集进度上下重排。

## 必须实现

1. 当前装扮人物通过统一 `AvatarRenderer` 渲染，商品试穿后及时更新但不提前永久保存。
2. 全部、发型、服饰、鞋履、配饰、背景、套装等分类来自真实商品数据。
3. 商品卡显示名称、类别、缩略图、价格、拥有状态以及试穿/购买操作。
4. 购买校验余额、拥有状态和异步结果；防止重复扣费与重复购买。
5. 试穿、取消试穿、重置装扮和确认穿戴保持清楚的状态边界。
6. 套装收集展示真实已拥有件数、缺失件、解锁奖励与领取状态。
7. 货币栏、区域奖励、返回旅程和继续答题复用现有业务入口。

## 禁止

- 使用参考图中的人物、服装、商品插画或价格作为真实数据；
- 购买按钮仅做视觉效果而不处理余额和失败状态；
- 试穿时直接覆盖玩家已保存装扮且无法撤销。

完成后执行同目录的 `QA_CHECKLIST.md`。

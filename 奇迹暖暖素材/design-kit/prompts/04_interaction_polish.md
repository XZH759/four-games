# 阶段 4：游戏感交互与操作精修

请在不改变业务规则的前提下加入精致、明确、低延迟的游戏交互。

必须实现：
1. 点击选项后立即选中，150–220ms 更新角色。
2. 新资源未加载完成前保持旧角色，不显示空白。
3. 选中卡片出现勾选章缩放动画，持续 180ms。
4. 套装切换采用交叉淡化和 2px 轻微位移，不使用翻转。
5. “随机生成”先按下反馈，再依次更新姓名、外观、套装，总时长不超过 650ms。
6. “确认进入”点击后锁定按钮，保存成功后进入下一页，避免重复提交。
7. 名称为空时在输入框附近提示，不使用浏览器 alert。
8. 键盘 Enter/Space 可选择卡片。
9. 支持 `prefers-reduced-motion`。
10. 为动态结果添加 aria-live。

建议时长：
- hover：120ms
- card selected：180ms
- avatar crossfade：220ms
- modal：180–240ms
- page transition：280–360ms

禁止：
- 每次点击都播放大量星星爆炸；
- 超过 700ms 的换装动画；
- 音效自动播放；
- 切换时页面整体重排或滚动跳动。

# 界面 08：抽卡盲盒

先读取：

```text
design-kit/interfaces/COMMON_REQUIREMENTS.md
design-kit/interfaces/08_blind-box/reference.png
```

只制作“抽卡盲盒/星光礼盒”流程。

## 页面目标

把章节进度、抽取资格、方式选择、翻牌/开启、奖励结果、历史记录和保底进度组织为一条可理解的状态流程。视觉可以有仪式感，但不得遮蔽概率、成本和实际结果。

## 必须实现

1. 使用明确状态机管理未解锁、可开启、选择方式、选择卡牌、开启中、结果和历史记录。
2. 抽取次数、资格、消耗、奖励池、概率或公平说明来自真实规则。
3. 点击确认后锁定相关操作，服务端/本地结果返回前不能重复抽取。
4. 开启动画结束后必须展示真实结果，不可在前端重新随机改变奖励。
5. 结果卡支持装备/查看，且物品同步进入衣柜或收藏数据。
6. 历史记录包含真实时间、奖励和本轮信息；空历史有合理状态。
7. 保底或章节进度由真实数据计算，领取次数与限制清楚。
8. `prefers-reduced-motion` 下跳过强光和长动画，直接安全显示结果。

## 禁止

- 隐藏实际消耗、概率、次数限制或失败结果；
- 用纯前端动画决定奖励；
- 全屏高亮闪烁、不可跳过的长动画或重复扣费。

完成后执行同目录的 `QA_CHECKLIST.md`。

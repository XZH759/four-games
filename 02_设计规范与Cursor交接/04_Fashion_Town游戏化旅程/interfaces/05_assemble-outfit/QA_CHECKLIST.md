# Step 5 验收

- [ ] 库存只显示真实已解锁模块，筛选数量与状态一致。
- [ ] 中央角色与前序保存的 avatar 是同一配置。
- [ ] 选择只改草稿，取消/刷新不会覆盖已保存造型。
- [ ] 保存造型幂等，名称为空和重复名称有页面内反馈。
- [ ] Style Identity 从模块标签计算，不硬编码参考分数。
- [ ] Companion Bond 和 Fashion role 读取真实状态。
- [ ] 缺少独立图层时无错位伪装，并列入 `ART-TODO`。
- [ ] 空库存、加载、错误和资源失败状态完整。
- [ ] Show in Park 不做无效假跳转；Visit Boutique 正确返回。
- [ ] 三种视口可筛选、换装、命名和保存，按钮不遮挡内容。

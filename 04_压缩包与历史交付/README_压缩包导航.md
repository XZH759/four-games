## 90_重复副本

此目录中的文件满足以下至少一项：

- 与另一文件 SHA-256 完全相同；
- 已经集成到 `character-reference`、`companions` 等项目目录；
- 是下载目录或 essay 根目录中遗留的重复副本。

重复文件没有删除，便于后续人工确认。日常给 Cursor 使用时应选择正式分类目录中的版本。

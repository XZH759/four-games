# 界面 04：关卡地图

先读取：

```text
design-kit/interfaces/COMMON_REQUIREMENTS.md
design-kit/interfaces/04_level-map/reference.png
```

只制作“关卡地图/学习旅程”界面。

## 页面目标

把章节、区域、节点、连线、宝箱和总体进度组织成可探索但清楚可读的学习地图。参考图中的五个彩色区域和路线只用于说明层级，不要求复制地形或固定节点位置。

## 必须实现

1. 地图区域、节点数量、完成度、锁定条件和奖励来自真实数据。
2. 节点具备已完成、当前、可进入、未解锁和奖励节点状态。
3. 连线能反映实际前置关系；缩放后仍与节点对齐。
4. 点击节点显示关卡名称、进度、奖励和进入操作，不直接误触开题。
5. 桌面可使用地图主区加进度侧栏；手机提供可控缩放/滚动和简化详情抽屉。
6. 提供“定位当前关卡”能力；若实现缩放，必须有明确控制和合理边界。
7. 装饰地图不能阻挡节点点击、键盘焦点或状态文字。

## 禁止

- 把参考图作为超大背景并在固定坐标覆盖按钮；
- 用纯颜色区分全部状态而没有图形或文字辅助；
- 在不同屏幕上按百分比随意漂移节点与连线。

完成后执行同目录的 `QA_CHECKLIST.md`。

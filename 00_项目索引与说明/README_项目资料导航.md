# essay 项目资料导航

本目录已按“运行代码保持原位、研究资料集中归档、图片按来源与用途分类、压缩包与展开目录分离”的原则整理。

## 主要目录

- `01_论文与研究资料`
  - 核心论文与 AI 素养题库
  - AAAI/EAAI、游戏化、AI 素养分类文献库
  - 文献笔记、真实性审查、实验方法提取
  - 投稿模板
- `02_设计规范与Cursor交接`
  - LevelUp 总体设计与 Cursor 构建规范
  - 角色创建、学习伙伴、跑酷模块的交接文件
  - 历史网页原型和素材裁切网页快照
- `03_美术与界面参考`
  - 角色创建、学习伙伴、世界地图、跑酷、AI 素养挑战赛
  - 文件名注明 `OpenAI生成`、`外部参考` 或 `来源未标注`
- `04_压缩包与历史交付`
  - 按角色创建、学习伙伴、世界地图等模块保存原始输入包
  - `90_重复副本` 保存哈希相同或已集成的副本，未直接删除
- `05_历史展开包`
  - 保存曾经解压到项目根目录的 Cursor 输入包
- `99_待确认与无效下载`
  - 保存 404 页面及其网页资源，避免与有效项目素材混放
- `奇迹暖暖素材`
  - 按 10 个界面环节重新分类
  - 保留 `design-kit` 的 Cursor 指令、验收清单和代码模板
  - 人物素材继续按角色、原版、Q 版及来源分层

## 保持原位的内容

以下目录或文件属于当前可运行网站及其工具链，未进行移动：

- `.git`、`.cursor`、`.vercel`、`node_modules`
- `index.html`、`package.json`、`vercel.json`
- `assets`、`avatar`、`castle`、`companions`、`css`、`js`
- `kahoot`、`monopoly`、`nuannuan`、`parkour`、`race`
- `character-assets`、`character-reference`、`qa-shots`

这样可以避免破坏 HTML、CSS、JavaScript、TypeScript 中的相对路径和部署配置。

## 使用建议

1. 给 Cursor 提供需求或素材时，优先从 `02_设计规范与Cursor交接` 和 `03_美术与界面参考` 选择。
2. 需要完整输入包时，从 `04_压缩包与历史交付` 取 ZIP，不要从 `90_重复副本` 取。
3. 论文写作时，以 `01_论文与研究资料/01_核心论文与题库` 为入口。
4. `05_历史展开包` 仅用于追溯历史版本，不应直接覆盖当前项目代码。

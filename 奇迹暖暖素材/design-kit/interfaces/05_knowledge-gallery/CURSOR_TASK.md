# 界面 05：AI 知识图鉴

先读取：

```text
design-kit/interfaces/COMMON_REQUIREMENTS.md
design-kit/interfaces/05_knowledge-gallery/reference.png
```

只制作“AI 知识图鉴/主题收藏”界面。

## 页面目标

建立一本可浏览的知识收藏册：侧边分类、主题卡片、当前主题详情、解锁条件和总收藏进度清楚关联。书册造型是视觉隐喻，实际内容仍须响应式和可访问。

## 必须实现

1. 分类、主题、已点亮/待解锁状态与解锁条件来自真实学习进度。
2. 选择主题卡后，详情标题、简介、条件和奖励同步更新。
3. 已解锁卡可进入对应内容；锁定卡不会误触跳转，并说明解锁条件。
4. 收藏进度由真实已解锁数量计算。
5. 桌面可使用展开书册与侧栏；手机改为顶部分类、卡片列表和下方详情，不强行保持双页书比例。
6. 卡片插画缺失时使用统一占位，不从参考图裁切插画。
7. 主题中英文名、术语和章节编号必须来自项目数据。

## 禁止

- 把整本书制作成不可缩放的固定背景；
- 为视觉效果隐藏解锁条件或状态文本；
- 使用参考图中的主题插画作为正式内容。

完成后执行同目录的 `QA_CHECKLIST.md`。
